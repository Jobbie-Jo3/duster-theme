#SALT TIP4Serv Storefront Redesign

This update refreshes the storefront around the single #SALT cluster identity.

Updated:
- New single-cluster homepage / hero section and product showcase.
- SALT orange updated to #FA4B00 with a dark survival-inspired visual system.
- Simplified responsive navigation: Home, Shop, configured external menu links and Cart.
- Removed the customer-facing cluster switcher from the navigation.
- Updated storefront metadata and shop copy.
- Updated footer branding.

Preserved:
- TIP4Serv API routes and API client.
- Product/category loading and product detail pages.
- Cart state, checkout, payment flow and checkout return pages.
- OAuth routes and existing configuration.
- Existing environment files are not included or changed.

Deployment:
1. Back up the current webshop folder.
2. Extract this ZIP over the project folder, replacing the included files.
3. Keep your existing .env.local / hosting environment variables unchanged.
4. Run `npm ci` then `npm run build` and deploy/restart using your normal hosting process.

Note: The project dependencies were not available in the build environment during this edit, so a full Next.js production build could not be completed here. No live TIP4Serv checkout or API transactions were run.
